Aprenda sobre desenvolvimento web utilizando HTML, CSS e Bootstrap.

Estrutura da Atividade

Nesta atividade, você aprenderá a organizar uma página web utilizando componentes e classes do Bootstrap.

Objetivos de aprendizagem

  • Criar um cabeçalho com menu responsivo.
  • Organizar o conteúdo principal em um container.
  • Utilizar cards para apresentar informações.
  • Construir um rodapé com links secundários.

Etapas da atividade

  1. Configure o arquivo HTML e importe o Bootstrap.
  2. Construa o menu de navegação com a classe navbar.
  3. Centralize o conteúdo com container e my-5.
  4. Organize o rodapé com flexbox.
